# Guitar Scores

This repository contains guitar scores that I have transcribed, edited, or engraved using [LilyPond](https://lilypond.org/). In the future, I hope to add some of my own compositions and variations for guitar.

The scores are available in LilyPond source format (`.ly`) and PDF.

Enjoy!
